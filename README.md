# Predictive Analytics — Course Hub

A modern, Gen-Z-friendly course portal for **Predictive Analytics** at Universitas Cakrawala.

## What is included

- 16-week semester roadmap
- Class schedule for **Wednesday & Thursday, 15:30–18:00 WIB**
- Weekly material, hands-on activity, and assessment labels
- Assessment tracker
- Learning stack overview
- Responsive layout optimized for mobile and desktop
- Interactive **Predictive Analytics Playground** with 5 mini-games, XP, badges, and instant feedback
- No environment variables required

## Tech stack

- Next.js 15
- React 19
- Plain CSS (no UI framework dependency)

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Import this GitHub repository into Vercel.
2. Vercel should auto-detect **Next.js**.
3. Use the default build command: `next build`.
4. No environment variables are required.

## Course rhythm

- **Rabu:** 15.30–18.00 WIB
- **Kamis:** 15.30–18.00 WIB
- Suggested flow per session: concept → live demo → guided hands-on → discussion/debrief

## Content source

The weekly roadmap follows the Predictive Analytics RPS used in this course and the teaching materials developed for weeks 1–15.

Learn → Build → Explain → Create impact.
